# SolveX – Your Smart Problem Solver

**SolveX** is a premium, fully functional, client-side web application designed to help users solve real-world problems through practical tools, structured guidance, weighted decision matrices, and actionable recommendations.

---

## 💡 Concept & Vision
* **Idea & Product Direction:** Nouman Lodhi
* **Engineering & Execution:** Developed collaboratively with advanced AI tools.

---

## 🚀 Core Features

1. **Smart Problem Solver:** 
   - Rule-based keyword matching and heuristic problem diagnosis engine.
   - Breaks solutions down into step-by-step actionable checklists with difficulty & priority ratings.
   - Export solutions to `.txt` or copy instantly to the clipboard.
2. **10 Built-In Daily Life Tools:**
   - Smart Budget Planner & Expense Calculator
   - Weighted Study Planner & Pomodoro/Time Management Tracker
   - Goal Tracker & Decision Maker
   - Productivity Calculator, Percentage Calculator, Age Calculator, and Unit Converter.
3. **Smart Decision Assistant:** 
   - Add multiple options, assign weighted pros and cons, and automatically calculate ranked recommendations.
4. **Productivity Dashboard & History:**
   - Live metrics calculating actual app usage, saved solutions, completed goals, and recent activities stored locally.
5. **Modern SaaS UI/UX:**
   - Sleek Deep Navy / Electric Blue design, smooth CSS transitions, fully responsive sidebar navigation, and native Dark/Light mode support.

---

## 🛠️ Technology Stack
* **HTML5** (Semantic structure)
* **CSS3** (Custom properties, responsive flex/grid layouts, clean animations)
* **Vanilla JavaScript (ES6+)** (Modular logic, state management, and `localStorage` persistence)
* *No frameworks, no backend, no external dependencies, and no paid APIs.*
